Before you connect

First get an API ID and API hash from Telegram. You will enter them on the next screen.

  1. Open my.telegram.org in a browser and sign in with the Telegram account that can access your chat.
  2. Enter the verification code Telegram sends to your account.
  3. Open API development tools. If asked, complete the form to create an API application.
  4. Copy the API ID (a number) and API hash (32 characters).

On the next screen, enter both values and tap Continue. Then scan the QR code with a logged-in Telegram app: open Settings → Devices → Link Desktop Device, scan the code, and approve the sign-in.

Your API ID and hash are not your Telegram phone number, sign-in code, or two-step verification password.
